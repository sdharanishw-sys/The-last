Problem Statement & Motivation

The Industrial BMS Threshold Dilemma

Why Conventional Fixed-Threshold Safety Systems Fail

The Fixed Threshold Trade-Off

  • Narrow Thresholds: Sport-mode driving (rapid 2.5C acceleration bursts) triggers false under-voltage alarms due to dynamic ohmic and polarization drop.
  • Wide Thresholds: Incipient degradation (+12 mΩ contact corrosion) and sensor calibration drift (+35 mV) remain completely undetected within wide static limits.
  • Cold Weather Traps: Sub-zero cold (-10°C) naturally increases cell internal resistance by ~2.5× via Arrhenius kinetics, tripping static alarms on healthy cells.

Execution Hierarchy

  • High-Frequency Protection (10 Hz): Exact discrete-time 2-RC state updates, non-finite telemetry rejection, and instantaneous safety cutoffs.
  • Intermediate Diagnostic Loop (0.1–1 Hz): Dynamic residual tracking, OLS impedance regression, and 20s resting dwell qualification.
  • Quasi-Static Calibration Loop: 4-stage baseline fingerprinting during scheduled vehicle rests and charging.

Fail-Safe Supervisory Actions

  • Thermal Trip: Instantaneous contactor disconnect if T ≥ 60.0°C.
  • Low-Voltage Cutoff: Contactor disconnect if V ≤ 2.80 V.
  • Sub-Zero Regen Lockout: Charge current clamped to 0 A if T ≤ 0.0°C.
  • Telemetry Guard: NaN/Inf rejected, last valid state latched.
Mathematical Modeling

Electro-Thermal Model Formulation

2-RC Thevenin Network, Monotone Spline & Thermal Balance

2-RC Thevenin Network

V_t(t) = V_ocv(SOC, T) - I(t)·R_0(T) - V_1(t) - V_2(t)
V_i[k+1] = V_i[k]·e^(-Δt/τ_i) + I[k]·R_i·[1 - e^(-Δt/τ_i)]
  • Fast Overpotential (V_1): Charge-transfer kinetics (τ_1 ≈ 0.5–5 s).
  • Slow Overpotential (V_2): Solid-state diffusion (τ_2 ≈ 20–60 s).
  • Fritsch-Carlson Spline: Guarantees strictly monotonic dOCV/dSOC > 0.

Thermal Balance & Arrhenius Kinetics

R_i(T) = R_{i,ref} · exp[ (E_{a,R} / R_g) · (1/T_cell - 1/T_ref) ]
C_th · (dT_cell / dt) = Q_gen - (T_cell - T_amb)/R_th + Q_ext
  • Joule Heating: Q_joule = I^2·R_0 + V_1^2/R_1 + V_2^2/R_2.
  • Reversible Heat: Q_entropic = -I · T_cell · (dV_ocv / dT).
  • Thermal Parameters: C_th = 65.0 J/K, R_th = 12.0 K/W.

Why Baseline Calibration is Critical

Cell-to-cell manufacturing variations naturally cause ±3% capacity dispersion and ±5% internal resistance differences. Without baseline calibration, these benign differences would trigger permanent false alarms.

Immutable Reference Profile

Once generated, the baseline parameters are frozen into an immutable profile representing healthy behavior for that specific pack, providing a clean ground-truth reference.

Diagnostic Innovation

Orthogonal Feature Extraction

Decoupling Ohmic Resistance from Sensor Calibration Bias

Feature 1: Dynamic Resistance Slope

β_R = (d V_res / d I) = [ Σ(I - I_avg)(e_V - e_V_avg) ] / Σ(I - I_avg)^2
  • Calculated via online OLS regression during active currents (|I| ≥ 0.5A).
  • Pure resistance degradation scales strictly proportional to current (slope β_R < 0).
  • Independent of constant sensor offsets.

Feature 2: Compensated Resting Voltage

V_{rest, comp} = e_V - (V_1,pred + V_2,pred)
  • 20-Second Rest Dwell: Only evaluated when |I| ≤ 0.05A continuously for ≥ 20.0s (200 timesteps).
  • Polarization Compensation: Subtracts predicted residual RC voltages.
  • Eliminates false sensor bias alarms caused by decaying polarization after aggressive driving!

Physical Analysis

The 6/16 Thermal Detection Limitation

Thermal Mass Inertia vs. Drive-Cycle Duration

The Physical Root Cause

τ_th = R_th · C_th = 12.0 K/W · 65.0 J/K = 780.0 s (13.0 min)
  • Thermal Time Constant: 13.0 minutes for cylindrical 18650 cell.
  • Drive-Cycle Duration: Test cycles run for 360 s (6.0 min) — less than half of one thermal time constant (0.46 τ_th).
  • Subtle vs. Severe Heat Flux:
    • Severe Heat Flux (≥ 2.5W): ΔT > 4.0°C within 180s ➔ Detected (98.9% Conf).
    • Mild Cooling Loss (30% reduction): ΔT excess only reached +1.8°C to +3.4°C over 360s ➔ Sub-threshold (< +4.0°C).

Engineering Significance & Safety

  • Physical Observability: Mild cooling degradation cannot be observed over a 6-minute window without multi-cycle thermal energy integration.
  • Safety Supervisor Protection: The primary safety cutoff at T ≥ 60.0°C remains fully active, guaranteeing hardware protection regardless of diagnostic attribution.
  • No False Alarms: Lowering the threshold below +4.0°C would cause false alarms during hot ambient hill climbs.
