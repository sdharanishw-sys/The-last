📖 FOUR CORE CONCEPTS ARCHITECTURE
① DAY-ONE FINGERPRINT
A permanent reference snapshot of the battery's initial pristine condition when it was manufactured. Stores rated capacity (100 Ah), nominal voltage (3.65 V), initial impedance (12 mΩ), and baseline OCV curves. This fingerprint remains immutable throughout vehicle lifetime.
② EXPECTED AGING SHADOW CURVE
The manufacturer-claimed degradation baseline modeling expected SOH decline over cycle count. The Adaptive Twin Reference model extends this baseline by dynamically managing current rates and thermal stress to push actual battery life well above the shadow curve.
③ LIVE SENSOR STREAM
Continuous real-time simulated telemetry generated by the 2-RC equivalent-circuit model, coulomb counting, and lumped thermal balance equations. All readings vary dynamically with simulated driver behavior and load transients.
④ DEVIATION ATTRIBUTION LAYER
Compares each dynamic live reading against the Day-One Fingerprint and aging shadow curve. Classifies deviations into NORMAL, WARNING, or CRITICAL status with colored warning lights to isolate degradation causes in real time.
